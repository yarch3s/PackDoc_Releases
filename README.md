# PackDoc

Программа отдела логистики NORREXIM DMCC. По Excel-файлу завода-изготовителя (листы Invoice и Packing list)
и спецификации формирует отгрузочный комплект: инвойсы, Packing list, Component List,
грузовые маркировки и черновик сертификата происхождения (DRAFT COO).

## Скачать

**[Скачать установщик PackDoc_Setup.exe](https://github.com/yarch3s/PackDoc_Releases/releases/latest/download/PackDoc_Setup.exe)** (последняя версия)

Инструкция: [PackDoc_Instrukciya.pdf](https://github.com/yarch3s/PackDoc_Releases/releases/latest/download/PackDoc_Instrukciya.pdf). Она же ставится вместе с программой:
меню «Пуск» → «Инструкция PackDoc».

Все версии и контрольные суммы SHA256: [страница выпусков](https://github.com/yarch3s/PackDoc_Releases/releases).

## Переносная версия

Для компьютеров, где нельзя установить WebView2 Runtime или запускать установщики:
**[PackDoc_Portable.zip](https://github.com/yarch3s/PackDoc_Releases/releases/latest/download/PackDoc_Portable.zip)**. Архив распаковывается в любую папку и работает без установки
и без прав администратора: компонент WebView2 лежит внутри. Как запустить, написано в файле `ПРОЧТИ.txt`
в архиве. Обновляется переносная версия сама, так же по кнопке «Обновить».

## Требования

- Windows 10 или 11, 64-бит.
- Права администратора не нужны: программа ставится в папку пользователя
  `%LOCALAPPDATA%\Programs\PackDoc`.
- Microsoft Edge WebView2 Runtime. В Windows 10 и 11 он обычно уже есть; если нет, установщик
  подскажет ссылку на сайт Microsoft.

## Установка и обновление

1. Скачайте `PackDoc_Setup.exe` и запустите.
2. Если Windows покажет окно «Windows защитила ваш компьютер» (SmartScreen), нажмите
   «Подробнее» → «Выполнить в любом случае».
3. Обновление. Начиная с версии 1.1.0 программа сама сообщает о новой версии: нажмите «Обновить», она скачает
   установщик, проверит его, установит и откроется снова. Версию 1.0.0 обновите один раз вручную: скачайте
   установщик по той же ссылке и запустите. Новая версия встанет поверх старой, открытую программу установщик
   закроет сам. База спецификаций и настройки при обновлении сохраняются.

## Данные

Программа работает на вашем компьютере: документы и данные отгрузок в интернет не отправляются.
В интернет она обращается только за одним: проверить на этой странице GitHub, не вышла ли новая версия,
и скачать её установщик. Без интернета программа работает как обычно.
База спецификаций и настройки хранятся в `%APPDATA%\PackDoc` и при удалении программы сохраняются.
